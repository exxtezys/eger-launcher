# Лаунчер «Егерь» 0.4.0 (тестовая версия)

Главное: **загрузка работает без VPN и без настроек** — если официальный сервер не отвечает, файлы автоматически берутся с зеркал.

## Что нового

- **Зеркала загрузок.** Каждый шаг (список версий, библиотеки, ресурсы, сам NeoForge, Java) сначала идёт на официальный адрес, а если он молчит — на зеркало. Ничего включать не нужно.
- **Разведка хостов.** При первой загрузке из группы лаунчер коротко проверяет, кто отвечает, и дальше сразу идёт к рабочему источнику, а не ждёт таймаут на каждом из тысяч файлов.
- **Выбор зеркала запоминается** между запусками (`mirror-choice.properties`), повторная разведка не нужна.
- **Повторы при обрывах.** Сбои на плохом канале идут «окнами», поэтому повтор идёт с нарастающей паузой (0.4 → 0.8 → 1.6 … до 5 с) — установка переживает моргание сети вместо падения.
- **Понятная ошибка.** Если не ответил ни один источник: одна строка с названием шага, подсказка про прокси и кнопка «Повторить». Подробности уходят в лог, а не в лицо игроку.
- **Битая загрузка — не блокировка.** Если файл не сошёлся по sha1, зеркало просто исключается из списка; игроку это не показывается как ошибка сети.
- **Проверка целостности.** Установщик NeoForge сверяется по sha1 из соседнего файла, Java 21 — по закреплённой версии и контрольной сумме.
- **Прокси главнее.** Если игрок включил свой прокси, зеркала отключаются — трафик идёт только через его настройки.

## Если что-то не качается

1. Нажмите «Повторить» — чаще всего помогает.
2. Включите VPN или свой прокси в настройках лаунчера.
3. Пришлите лог: `%APPDATA%\.eger\launcher.log`.
